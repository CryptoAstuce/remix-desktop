# 6. Perimetre documentaire

Ce parcours couvre le shell Electron, l acces aux fichiers, l IPC, le packaging et les differences avec l IDE web. Il s appuie sur main.js, config.js, applicationMenu.js, selectFolder.js, package.json, build et le README du depot. Il ne couvre pas la nouvelle generation de Remix Desktop ni la verification des binaires publies. Le depot amont indique lui-meme que cette version est obsolete ; toute reprise doit donc commencer par le projet recommande dans cette indication. Aucune installation, compilation, execution ou test n a ete realise. Les suites de tests presentes dans le depot peuvent etre consultees par un mainteneur qui souhaite verifier le comportement dans un environnement controle.
