# 5. Reseaux, portefeuille et limites

Le README distingue Desktop de l IDE web sur l injection de portefeuille. L application bureau ne beneficie pas directement de l extension navigateur MetaMask ; un plugin WalletConnect est donc mentionne pour le deploiement vers un reseau public. Cette difference change le parcours utilisateur sans changer le role du provider RPC et de la signature. Les chemins locaux et les integrations externes doivent etre expliques avant toute transaction. Le depot etudie ici est marque deprecated et pointe vers une implementation plus recente : il sert surtout a comprendre un modele historique d emballage. Il ne faut pas deduire que ses versions ou pratiques sont encore recommandees. Les limites de ce chapitre sont documentaires : aucune connexion ni transaction n a ete realisee.
