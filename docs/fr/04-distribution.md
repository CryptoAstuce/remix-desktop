# 4. Distribution et packaging

Le dossier build et package.json decrivent la fabrication des versions distribuables. Une application Electron regroupe le shell natif, les ressources web et les metadonnees necessaires aux plateformes Linux, Windows et macOS. Le processus de release doit aligner version, artefacts, signatures et notes de migration. Le README renvoie vers les releases GitHub pour telecharger l application et vers la documentation Remix pour le coeur IDE. Cette distribution apporte une autonomie locale mais rend chaque mise a jour dependante d un nouvel artefact. Les utilisateurs doivent privilegier les canaux officiels et verifier l origine des fichiers. Les limites de ce chapitre sont documentaires : aucun paquet n a ete construit ou installe.
